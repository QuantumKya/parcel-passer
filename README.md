# Parcel Passer
### A little web game for [@richardkiselev](github.com/richardkiselev)'s PassTheParcel project.

Pass the parcel from platform to platform to deliver the stickers to Hack Club HQ!  
Don't drop too many, they need enough to deliver!

![Parcel Art](parcel.png)

## Description
Parcel Passer is a web game about passing a parcel from platform to platform over periodic precarious pits! I made the game in HTML and JavaScript, but all JavaScript code is in the HTML file's `script` tags. To play it, you need a web browser that runs JS.
