# Parcel Passer
### A little web game for @richardkiselev's PassTheParcel project.

Pass the parcel from platform to platform to deliver the stickers to Hack Club HQ!  
Don't drop too many, they need enough to deliver!

![Parcel Art](parcel.png)

### Controls:
Aim and control velocity with the mouse. The aiming power and size is as intuitive as I could make it.
